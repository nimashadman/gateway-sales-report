گزارش فروش ووکامرس بر اساس درگاه‌های پرداخت، با انتخاب بازه تاریخ شمسی و خروجی اکسل فارسی.

== Description ==

Parsi Gateway Sales Report for WooCommerce یک افزونه گزارش‌گیری فارسی برای فروشگاه‌های ووکامرسی است.

این افزونه همه درگاه‌های پرداخت نصب‌شده را تشخیص می‌دهد، سفارش‌های تکمیل‌شده و پرداخت‌شده را در بازه تاریخ شمسی بررسی می‌کند و گزارش فروش را به صورت جمع کل، تفکیک‌شده بر اساس درگاه، و همراه با جزئیات سفارش‌ها نمایش می‌دهد.

توسعه‌دهنده: نیما شادمان

وب‌سایت توسعه‌دهنده: https://nimashadman.ir

== Features ==

* تشخیص خودکار درگاه‌های پرداخت ووکامرس
* گزارش جمع کل فروش
* گزارش تفکیکی هر درگاه پرداخت
* انتخاب بازه زمانی با تاریخ شمسی
* خروجی اکسل فارسی، راست‌به‌چپ و مرتب
* نمایش اعداد فارسی در خروجی
* سازگار با HPOS ووکامرس
* محدود به سفارش‌های completed و پرداخت‌شده

== Installation ==

1. پوشه افزونه را در مسیر `/wp-content/plugins/parsi-gateway-sales-report` قرار دهید.
2. افزونه را از بخش افزونه‌های وردپرس فعال کنید.
3. از مسیر WooCommerce > Gateway Sales Report وارد صفحه گزارش شوید.

== Frequently Asked Questions ==

= آیا افزونه به کتابخانه خارجی نیاز دارد؟ =

خیر. تبدیل تاریخ شمسی و خروجی اکسل درون خود افزونه پیاده‌سازی شده است.

= چه سفارش‌هایی در گزارش محاسبه می‌شوند؟ =

فقط سفارش‌هایی که پرداخت موفق داشته باشند و وضعیت آن‌ها completed باشد.

= خروجی اکسل با چه فرمتی ساخته می‌شود؟ =

خروجی با فرمت Excel-compatible XLS ساخته می‌شود تا روی بیشتر نصب‌های وردپرس بدون وابستگی خارجی قابل استفاده باشد.
